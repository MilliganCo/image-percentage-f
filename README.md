# Image Percentage F

## Описание

Небольшое desktop-приложение на Python для анализа PDF-файлов: оно извлекает изображения из документа, оценивает процент заполнения по альфа-каналу и сохраняет результаты в Excel.

Проект полезен как быстрая локальная утилита для проверки графических материалов, где важно понять, насколько изображение фактически занято непрозрачным содержимым.

## Возможности

- выбор PDF через простое графическое окно;
- извлечение встроенных изображений из PDF;
- расчёт процента заполнения по прозрачности;
- сохранение статистики в `PDF_Analysis.xlsx`;
- защита от повторного добавления одного и того же файла в таблицу.

## Стек

- Python
- Tkinter
- PyMuPDF
- Pillow
- NumPy
- openpyxl

## Статус

## Как использовать

1. Установите зависимости проекта.
2. Запустите `perc.py`.
3. Выберите PDF-файл в диалоге.
4. После обработки проверьте файл `PDF_Analysis.xlsx`.

## Замечания

- Для PDF без встроенных изображений приложение сообщает об ошибке.
- Если у изображения нет альфа-канала, оно считается полностью заполненным.
